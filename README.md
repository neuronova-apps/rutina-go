# rutina-go

Aplicación de rutinas visuales para la organización diaria, la autonomía y el desarrollo de actividades paso a paso. Desarrollada por NeuroNova Apps.

RutinaGo es una iniciativa completamente gratuita y sin fines de lucro. No incluye publicidad, compras integradas, suscripciones ni funciones premium. Esta decisión corresponde específicamente a RutinaGo y no modifica el modelo de distribución de otras aplicaciones de NeuroNova Apps.
